# 数据库管理系统（DBMS）接口文档

**版本**：2.0  
**日期**：2026-04-19  
**通信方式**：TypeScript 模块直接调用（CLI 层 → 引擎层）

---

## 概述

所有交互通过 **函数调用** 完成。CLI 层（`src/cli/`）直接 `import` 引擎入口 `DBEngine`，调用其方法获得结构化结果，再由 formatter 渲染到终端。

### 统一结果类型

```typescript
// src/types.ts

export interface QueryResult {
  type: 'SELECT' | 'DDL' | 'DML' | 'ERROR'
  // SELECT 时
  columns?: ColumnMeta[]
  rows?: any[][]
  rowCount?: number
  // DML 时
  affectedRows?: number
  insertId?: number
  // 通用
  message?: string
  error?: DBError
  elapsedMs?: number      // 执行耗时（由引擎填充）
}

export interface ColumnMeta {
  name: string
  type: FieldType
}

export interface DBError {
  code: ErrorCode
  message: string
}

export type FieldType = 'INTEGER' | 'DOUBLE' | 'BOOL' | 'VARCHAR' | 'DATETIME'
```

## 1. 引擎主入口（DBEngine）

```typescript
// src/engine/DBEngine.ts

export interface DBEngine {
  /**
   * 执行任意 SQL 语句
   * @param sql     SQL 字符串（单条语句，不含末尾分号）
   * @param session 当前会话状态（当前库、事务 ID 等）
   */
  execute(sql: string, session: Session): Promise<QueryResult>

  /** 开启事务 */
  beginTransaction(session: Session): Promise<void>

  /** 提交事务 */
  commit(session: Session): Promise<void>

  /** 回滚事务 */
  rollback(session: Session): Promise<void>
}

export interface Session {
  sessionId: string       // 会话唯一标识（CLI 启动时生成）
  currentDatabase?: string
  transactionId?: string
  user?: string           // 当前登录用户
}
```

> CLI REPL 通过 `engine.execute(sql, session)` 驱动所有操作，无需感知内部模块。

## 2. 存储引擎子模块接口

### 2.1 DatabaseManager

```typescript
// src/engine/storage/DatabaseManager.ts

export interface DatabaseManager {
  /** 初始化引擎，创建 data 目录与 .mdb 系统文件（若不存在） */
  init(dataDir: string): Promise<void>

  /** 返回所有数据库名 */
  listDatabases(): Promise<string[]>

  /** 创建数据库目录与元信息 */
  createDatabase(name: string): Promise<void>

  /** 删除数据库目录（含所有表文件） */
  dropDatabase(name: string): Promise<void>

  /** 检查数据库是否存在 */
  databaseExists(name: string): Promise<boolean>
}
```

---

### 2.2 TableManager

```typescript
// src/engine/storage/TableManager.ts

export interface TableManager {
  /** 列出指定数据库下的所有表名 */
  listTables(database: string): Promise<string[]>

  /** 读取表结构定义 */
  describeTable(database: string, table: string): Promise<TableDefinition>

  /** 创建表（写入 .tdf 文件） */
  createTable(database: string, def: TableDefinition): Promise<void>

  /** 删除表（删除 .tdf 与 .trd 文件） */
  dropTable(database: string, table: string): Promise<void>

  /** 添加字段 */
  addColumn(database: string, table: string, col: ColumnDefinition): Promise<void>

  /** 修改字段 */
  modifyColumn(database: string, table: string, colName: string, changes: Partial<ColumnDefinition>): Promise<void>

  /** 删除字段 */
  dropColumn(database: string, table: string, colName: string): Promise<void>
}

export interface TableDefinition {
  name: string
  columns: ColumnDefinition[]
}

export interface ColumnDefinition {
  name: string
  type: FieldType
  length?: number        // VARCHAR 长度
  nullable: boolean      // 默认 true
  defaultValue?: string
  primaryKey: boolean
  autoIncrement: boolean
  unique: boolean
}
```

---

### 2.3 RecordManager

```typescript
// src/engine/storage/RecordManager.ts

export interface RecordManager {
  /** 插入一条记录，返回新记录的物理偏移 */
  insert(database: string, table: string, record: Record<string, any>): Promise<number>

  /**
   * 全表扫描读取记录（不过滤，由 Executor 做 WHERE 过滤）
   * 返回字段值数组（顺序与 TableDefinition.columns 对应）
   */
  scan(database: string, table: string): Promise<any[][]>

  /** 按物理偏移更新记录 */
  update(database: string, table: string, offset: number, record: Record<string, any>): Promise<void>

  /** 按物理偏移标记删除（软删除）*/
  delete(database: string, table: string, offset: number): Promise<void>
}
```

---

### 2.4 IndexManager

```typescript
// src/engine/storage/IndexManager.ts

export interface IndexManager {
  /** 创建 B+Tree 索引，写入 .tid 文件 */
  createIndex(database: string, table: string, indexName: string, columns: string[], unique: boolean): Promise<void>

  /** 删除索引文件 */
  dropIndex(database: string, table: string, indexName: string): Promise<void>

  /**
   * 通过索引查找满足条件的记录物理偏移列表
   * @param key 查找键值
   */
  lookup(database: string, table: string, indexName: string, key: any): Promise<number[]>

  /** 列出指定表的所有索引 */
  listIndexes(database: string, table: string): Promise<IndexDefinition[]>
}

export interface IndexDefinition {
  name: string
  columns: string[]
  unique: boolean
}
```

### 4.2 Formatter（结果格式化）

```typescript
// src/cli/formatter.ts

export interface Formatter {
  /** 将 QueryResult 渲染为终端字符串（表格 / 受影响行数 / 错误信息） */
  format(result: QueryResult): string

  /** 分页输出（超过 pageSize 行时暂停等待输入） */
  formatPaged(result: QueryResult, pageSize: number): AsyncGenerator<string>
}
```

### 4.3 元命令处理

```typescript
// src/cli/metaCommands.ts

export type MetaResult =
  | { handled: false }                      // 非元命令，交给引擎解析
  | { handled: true; output: string }       // 处理完毕，直接输出

export interface MetaCommandHandler {
  /**
   * 判断并处理元命令（以 \ 开头或 source）
   * @param input   用户原始输入
   * @param session 当前 CLI 会话
   */
  handle(input: string, session: CLISession): MetaResult
}
```

## 5. 错误码列表

| 错误码 | 含义 |
|---|---|
| `DB_ALREADY_EXISTS` | 数据库已存在 |
| `DB_NOT_FOUND` | 数据库不存在 |
| `DB_SYSTEM` | 系统数据库不可操作 |
| `DB_NAME_INVALID` | 数据库名不合法 |
| `TABLE_ALREADY_EXISTS` | 表已存在 |
| `TABLE_NOT_FOUND` | 表不存在 |
| `TABLE_NAME_INVALID` | 表名不合法 |
| `COLUMN_NOT_FOUND` | 字段不存在 |
| `COLUMN_ALREADY_EXISTS` | 字段已存在 |
| `COLUMN_INVALID` | 字段定义不合法 |
| `CONSTRAINT_VIOLATION` | 完整性约束违反 |
| `DUPLICATE_KEY` | 主键/唯一键冲突 |
| `FOREIGN_KEY_VIOLATION` | 外键约束违反 |
| `TRANSACTION_NOT_FOUND` | 事务不存在 |
| `TRANSACTION_CONFLICT` | 事务操作冲突 |
| `PERMISSION_DENIED` | 权限不足 |
| `SQL_SYNTAX_ERROR` | SQL 语法错误 |
| `FILE_IO_ERROR` | 文件读写失败 |
| `UNKNOWN_ERROR` | 未知错误 |

## 6. 典型调用流程

```
用户输入 SQL → REPL 检测到 `;` 结尾
       │
       ▼
MetaCommandHandler.handle()    ← 若是 \help 等元命令直接处理
       │ 非元命令
       ▼
Lexer.tokenize(sql)            → Token[]
       │
       ▼
Parser.parse(tokens)           → ASTNode
       │
       ▼
Executor.execute(ast, session) → QueryResult
       │
       ▼
Formatter.format(result)       → 终端字符串
       │
       ▼
打印到 stdout，显示下一个提示符
```
