# 数据库管理系统（DBMS）接口文档

**版本**：1.0  
**日期**：2026-04-16  
**通信方式**：Electron IPC（`ipcMain` / `ipcRenderer`）

---

## 概述

所有前端（渲染进程）与后端（主进程）的通信均通过 IPC 通道进行。  
渲染进程通过 `window.dbmsAPI.xxx()` 调用（通过 preload 暴露），主进程处理并返回结果。

### 统一响应格式

```typescript
interface IpcResponse<T = any> {
  success: boolean      // 是否成功
  data?: T              // 成功时的返回数据
  error?: string        // 失败时的错误信息
  errorCode?: string    // 错误码（如 'CONN_FAILED', 'TABLE_EXISTS'）
}
```

## 1. 连接管理（Connection）

### 1.1 测试连接

- **通道**：`connection:test`
- **方向**：Renderer → Main

**请求参数**：
```typescript
{
  host: string        // 主机地址，如 "localhost"
  port: number        // 端口，DBMS 服务端监听端口
  user: string        // 用户名（DBMS 内部用户）
  password: string    // 密码
}
```

**响应**：
```typescript
IpcResponse<{
  version: string     // DBMS 版本，如 "1.0.0"
}>
```

---

### 1.2 建立连接

- **通道**：`connection:connect`
- **方向**：Renderer → Main

**请求参数**：
```typescript
{
  id: string          // 连接ID（客户端生成，UUID）
  name: string        // 连接名称（展示用）
  host: string
  port: number
  user: string
  password: string
  database?: string   // 默认数据库（可选）
}
```

**响应**：
```typescript
IpcResponse<{
  connectionId: string  // 服务端分配的连接标识
}>
```

---

### 1.3 断开连接

- **通道**：`connection:disconnect`
- **方向**：Renderer → Main

**请求参数**：
```typescript
{ connectionId: string }
```

**响应**：`IpcResponse<null>`

---

### 1.4 获取已保存连接列表

- **通道**：`connection:list`
- **方向**：Renderer → Main（查询本地持久化配置）

**响应**：
```typescript
IpcResponse<Array<{
  id: string
  name: string
  host: string
  port: number
  user: string
  dbType: string
  createdAt: string
}>>
```

## 5. 数据管理（Data）

### 5.1 查询数据

- **通道**：`data:query`

**请求参数**：
```typescript
{
  connectionId: string
  database: string
  table: string
  where?: string        // WHERE 子句，如 "id = 1"
  orderBy?: string      // 如 "id DESC"
  page?: number         // 页码，从 1 开始，默认 1
  pageSize?: number     // 每页条数，默认 100
}
```

**响应**：
```typescript
IpcResponse<{
  columns: string[]
  rows: any[][]
  total: number
  page: number
  pageSize: number
}>
```

---

### 5.2 执行自定义 SQL

- **通道**：`data:execute`

**请求参数**：
```typescript
{
  connectionId: string
  database: string
  sql: string           // 完整 SQL 语句
}
```

**响应**：
```typescript
IpcResponse<{
  // SELECT 时返回：
  columns?: string[]
  rows?: any[][]
  rowCount?: number
  // DML 时返回：
  affectedRows?: number
  insertId?: number
  message?: string
}>
```

---

### 5.3 插入记录

- **通道**：`data:insert`

**请求参数**：
```typescript
{
  connectionId: string
  database: string
  table: string
  record: Record<string, any>   // 列名 → 值
}
```

**响应**：
```typescript
IpcResponse<{
  insertId: number
  affectedRows: number
}>
```

**错误码**：
- `CONSTRAINT_VIOLATION`：完整性约束违反
- `DUPLICATE_KEY`：主键/唯一键冲突

---

### 5.4 更新记录

- **通道**：`data:update`

**请求参数**：
```typescript
{
  connectionId: string
  database: string
  table: string
  changes: Record<string, any>  // 要更新的列和值
  where: string                  // WHERE 子句（必填，防止全表更新）
}
```

**响应**：
```typescript
IpcResponse<{ affectedRows: number }>
```

---

### 5.5 删除记录

- **通道**：`data:delete`

**请求参数**：
```typescript
{
  connectionId: string
  database: string
  table: string
  where: string   // WHERE 子句（必填）
}
```

**响应**：
```typescript

```

```typescript
  filePath: string

}>
```

---

- **通道**：`maintenance:restore`

**请求参数**：
```typescript
{
  connectionId: string
  database: string

}
```

**响应**：
```typescript
IpcResponse<{
  executedStatements: number
  errors: string[]      // 有错误但继续执行时记录
```

## 10. 错误码列表

| 错误码 | 含义 |
|---|---|
| `CONN_FAILED` | 连接失败 |
| `CONN_NOT_FOUND` | 连接ID不存在 |
| `DB_ALREADY_EXISTS` | 数据库已存在 |
| `DB_NOT_FOUND` | 数据库不存在 |
| `DB_SYSTEM` | 系统数据库不可操作 |
| `DB_NAME_INVALID` | 数据库名不合法 |
| `TABLE_ALREADY_EXISTS` | 表已存在 |
| `TABLE_NOT_FOUND` | 表不存在 |
| `TABLE_NAME_INVALID` | 表名不合法 |
| `COLUMN_NOT_FOUND` | 字段不存在 |
| `COLUMN_ALREADY_EXISTS` | 字段已存在 |
| `COLUMN_INVALID` | 字段定义不合法 |
| `CONSTRAINT_VIOLATION` | 完整性约束违反 |
| `DUPLICATE_KEY` | 主键/唯一键冲突 |
| `FOREIGN_KEY_VIOLATION` | 外键约束违反 |
| `TRANSACTION_NOT_FOUND` | 事务不存在 |
| `PERMISSION_DENIED` | 权限不足 |
| `SQL_SYNTAX_ERROR` | SQL 语法错误 |
| `UNKNOWN_ERROR` | 未知错误 |
